Algorithmic Patterns Flashcards

Pre-Interview Mental Blueprints & Invariants

1. Two Pointers Convergence

Trigger: Sorted arrays/strings searching for pairs or palindromes.

Invariant: left = 0, right = n - 1 while left < right.

Time: O(N) | Space: O(1)
2. Sliding Window

Trigger: Longest/shortest contiguous subarray condition.

Invariant: Expand right, shrink left while condition violated.

Time: O(N) | Space: O(K)
3. Binary Search Space

Trigger: Monotonic condition or finding boundary value.

Invariant: mid = left + (right - left) / 2.

Time: O(log N) | Space: O(1)
4. Monotonic Stack

Trigger: Next Greater Element or Largest Rectangle.

Invariant: Pop smaller elements when higher arrives.

Time: O(N) | Space: O(N)
